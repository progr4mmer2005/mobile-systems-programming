# Что это за репозиторий?

Репозиторий студента группы **4411** Наумова Дениса Олеговича, обучающегося по специальности **Программная инженерия** на кафедре **Прикладная математика и информатика (ПМИ)** в университете **КНИТУ-КАИ им. А.Н. Туполева**, посвящён выполнению лабораторных работ по курсу **Программирование мобильных систем**.

Каждая ветка репозитория представляет из себя отдельную выполненную лабораторную работу. Каждая ветка (и лабораторная работа) делится на коммиты с подробным описанием того, что было сделано на каждом отдельном шаге выполнения курса.

Всего на курсе предусмотрено **8** лабораторных работ. Выполнение лабораторных работ подразумевает прохождение онлайн-курса [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course):

- первые **2 (два) юнита (unit)** онлайн-курса — первые две лабораторные работы;
- остальные лабораторные работы — по **3 (три) pathways** *каждая*.

Для выполнения всех лабораторных работ надо пройти **4 (четыре) юнита**.
